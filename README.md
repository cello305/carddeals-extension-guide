## 🛠️ Step-by-Step Installation Guides

### 1️⃣ Installing on Google Chrome & Chromium Browsers (Brave, Opera, Vivaldi)

1. **Download the Zip Package**: Download [`carddeals-extension-chrome.zip`](./downloads/carddeals-extension-chrome.zip) to your computer.
2. **Extract the Archive**: Right-click the `.zip` file and extract/unzip it into a permanent folder (e.g., `Documents/CardDealsExtension`).
3. **Open Extensions Page**: Open Google Chrome and type `chrome://extensions` in the address bar and press **Enter**.
4. **Enable Developer Mode**: In the top-right corner of the Extensions page, toggle the **Developer mode** switch to **ON**.
5. **Load Unpacked Extension**:
   - Click the **Load unpacked** button in the top-left menu bar.
   - Navigate to and select the unzipped folder containing `manifest.json`.
6. **Pin & Save**: Click the puzzle piece icon in Chrome's top bar and pin **CardDeals**. Visit [https://carddeals.co](https://carddeals.co) or any supported store to start saving!

---

### 2️⃣ Installing on Microsoft Edge

1. **Download the Zip Package**: Download [`carddeals-extension-edge.zip`](./downloads/carddeals-extension-edge.zip).
2. **Extract the Archive**: Unzip the archive into a folder on your machine.
3. **Open Edge Extensions**: Open Microsoft Edge and navigate to `edge://extensions`.
4. **Enable Developer Mode**: Turn on the **Developer mode** toggle switch in the bottom-left navigation menu.
5. **Load Unpacked Extension**:
   - Click the **Load unpacked** button near the top of the page.
   - Select the extracted extension directory.
6. **Done**: The CardDeals extension is now active on Microsoft Edge!

---

### 3️⃣ Installing on Mozilla Firefox

1. **Download the Zip Package**: Download [`carddeals-extension-firefox.zip`](./downloads/carddeals-extension-firefox.zip).
2. **Extract the Archive**: Extract the `.zip` file into a local folder.
3. **Open Firefox Debugging**: Open Firefox and enter `about:debugging#/runtime/this-firefox` in the address bar.
4. **Load Temporary Add-on**:
   - Click **Load Temporary Add-on…**.
   - Navigate into the unzipped folder and select `manifest.json`.
5. **Start Shopping**: CardDeals is now temporarily enabled and ready to find deals for you.
